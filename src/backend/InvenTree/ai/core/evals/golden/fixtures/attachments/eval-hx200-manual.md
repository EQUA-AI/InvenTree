# HX-200 Plate Heat Exchanger — Maintenance Manual (Eval Fixture)

This document is a reserved evaluation fixture for the attachment-RAG golden
set (fixture-set `aimms-attachment-fixtures-v1`). It is deliberately
fictional. Never edit it in place: content changes require a new fixture-set
version.

## 1. Gasket replacement

Replace plate gaskets whenever a plate pack is opened. Clean the gasket
grooves with a non-metallic scraper and isopropyl alcohol before seating the
new gasket.

### 1.1 Tightening

Tighten the frame bolts of the HX-200 to **38 Nm** in a cross pattern,
working from the centre pair outward. Re-check every bolt after the first
thermal cycle.

## 2. Inspection schedule

Perform a visual leak inspection of the HX-200 plate pack every
**6 months**. A full plate-pack teardown inspection is required every
36 months or after any overpressure event.

## 3. Operating limits

| Parameter | Limit |
| --- | --- |
| Maximum operating pressure | 16 bar |
| Maximum inlet temperature | 150 °C |
| Minimum flow (fouling guard) | 12 m³/h |

Exceeding the maximum operating pressure of 16 bar voids the pressure-vessel
certification.
