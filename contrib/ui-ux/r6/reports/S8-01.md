## Missing facts and open delivery items

- The frontend location/context API does not expose the server's `AIMMS_PLANT_TIMEZONE`. Location timezone is not substituted for plant time. Browser record/observation display zones are named; a supplied valid plant setting is supported and tested.
- The Machines list has no telemetry observation timestamps, run/stop projection or physical communication-status fact. Record-read time is not telemetry freshness. Offline / no current data is not called communication loss.
- Mimic polling metadata can report `connection_failed`, but does not establish physical communication loss or measured flow direction. The corresponding capture shows the polling error and honest communication unavailable. A true communication-lost verdict cannot be fabricated from this API.
- Model geometry and draft component assignments remain unverified reference/inference data. No physical, safety, service or healthy outcome is inferred.
- No database was read, no Azure writes / migrations / dry runs / app startup against Azure occurred, and no backend change or Django test was required. No dependency was installed or downloaded. Shared ledgers and other checkouts were not edited; all work remains uncommitted.
- Hyperagent scoring, coordinator review and connected/deployed R6 acceptance remain open.
