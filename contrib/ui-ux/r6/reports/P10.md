## Built

- Row click or keyboard-operable signal button selects the same canonical binding as the native Parameter control. Selection opens a named evidence region and moves focus to its heading. Closing restores the original trigger, with a chart-button fallback if filtering removed that trigger. Selection resets on a different machine (one `key` line in MachineDetail).
- Full-chart expansion uses Mantine Modal and the original 320 px blue AreaChart, linear curve, fill, timestamp/null/gap preparation, Parameter, Range and six-hour custom capability. Selection, range, custom form and the history query remain owned outside the modal, so expand/close does not reset them or initiate another window read. Modal close restores the expansion button. A removed binding remains explicitly unavailable instead of substituting another signal.
- Evidence names source/tag, dictionary component and assignment status, unit/kind, latest reading, observation on the dashboard clock, reception on the AIMMS clock, freshness/quality, native state, configured bounds, canonical anomaly/work citations and recent retained snapshot references. Stale values say Last-known. Missing limits, units, mappings, failed reads and unavailable association remain explicit.
- Reviewed and retained the predecessor's component projection. It uses `select_related`, adds no query per row, and now refuses an inconsistent point/component belonging to another machine. Tests cover those corrupt/imported associations as well as verified, draft and missing components.
