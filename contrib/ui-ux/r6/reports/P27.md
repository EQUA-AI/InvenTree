## Built

The native Work panel now consumes `time_assignment.v1`: typed assignee, separately labelled legacy assignee, matching latest native assignment event, actor, recorded reason, time and elapsed assignment wall time measured at the last server read. The anchor is usable only when the latest event's strict integer assignee ID matches the current typed assignee and its timestamp is not in the future. Malformed/stale/future events never fall back to an earlier assignment or job start. An audit accordion retains native assignment changes. Blank reasons remain unrecorded, not invented assignment factors or scores.

Native job actual start/completion remain separate from person-work intervals. The panel explicitly states attributed intervals unavailable and coverage unknown: gap durations and labor totals cannot be measured. Held work does not classify every person's time as Waiting; a photo/capture gap, transcript duration or browser activity does not classify labor. No live browser timer, invented zero total, accepted responsibility or unsupported correction button was added. Elapsed wall time is static until a new server read. Accepted handover, decision factors and interval correction providers are explicitly absent.

This checkout places the bounded projection in Work only. Closeout/History and time/report/assignment destinations owned elsewhere were not altered or presented as completed screens.
