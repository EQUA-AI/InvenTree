## Built to the available contract

- Preserve the backend's current assessment and all five native state words/icons. Badges no longer flex-shrink into truncated labels. A source observation, current assessment, active anomalies and coverage are separate facts. The summary does not mark its newest observation stale just because some other row is stale.
- Count mapped, usable-now and server-evaluated-now signals from the successful signal read. Current usable data requires an observation/value, good source quality and a non-stale flag; only native Normal/Warning/Critical classifications count as evaluated. Zero remains a real value. Failed reads show coverage unavailable. **Critical coverage unavailable** remains beside even a Normal assessment: a critical threshold is not a critical-signal designation. No frontend machine score or all-healthy verdict is introduced. Assessment time is explicitly not supplied.
- Keep all ten table fields in this scan order: Signal, Value, State, Trend, Observed, Current condition, Active anomalies, Quality, Source, Limits. Desktop keeps the native table in local scrolling. At phone width, the same semantic table rows use a card layout with their original 120×28 graphs visible beside identity/state; **All columns table** offers the wide table. The phone cards preserve explicit table/row/cell/header roles; generated visual labels are excluded from accessible cell names. Value, state, trend, observation and condition stay visible. Anomalies, quality, source and limits use a per-row phone disclosure; desktop and the wide-table option keep all columns. Rendered checks cover this layout.
- Rows name dictionary components, explain only their own supplied classification/limits or why they are not assessed, and associate anomalies only through canonical binding IDs. Links use the anomaly's actual owning work ID. Missing association, failed/incomplete active lists and known nonmatching bindings are distinct; no tag matching and no per-row work requests. The existing one-batch trend cache is preserved.
- Component/search filters remain local and explicit. Counts state their scope; an out-of-filter selection keeps its chart/evidence, and an empty component result never silently becomes machine-wide. Source/tag, quality and bounds remain accessible in the disclosure. Threshold wording follows the native classifier (below a minimum, above a maximum), with units; normal bounds are labelled as configured minima/maxima. Unknown anomaly associations state that an active machine anomaly does not name its signals, with correct plurals. Anomaly actions wrap on phones; failed past-alarm reads no longer report no past alarms.
- Current navigation stays current. A separate retained-evidence disclosure opens `?snapshot=<UUID>` and shows the exact immutable snapshot's identity/hash, source/anomaly, original window, capture/observation times with timezone, quality, stale-at-capture state and captured values. It does not reconstruct absent history or replace current readings/graphs. Return clears only the snapshot parameter.
- Mapping found one provider gap: `snapshots/` returned only the newest 50, so an older exact citation could not be resolved. An additive `snapshot` query parameter on that existing machine-scoped read now resolves one UUID beyond that limit. Machine authorization still runs first; lookup remains filtered by that machine. Malformed, missing, another-machine and denied-scope references fail closed. No migration or write endpoint was added.
