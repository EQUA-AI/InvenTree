## What was built

- **One shared trend reading** (`trendSamples.ts`, pure): every sample is kept at its own source time and sorted by time. A sample that cannot be drawn (not a number, or a number the source did not report `good`, the same rule as Performance's `usable` and the current-value rows) stays in the record as a null at its time. A silence longer than the source cadence becomes a display-only break (`measured: false`, never counted or shown as a sample). The cadence threshold reuses the Performance helper `gapThresholdMs` with the same semantics (complete read at source cadence); no universal threshold is invented.
- **120 x 28 row graph** (`SignalTrend.tsx`): x is now elapsed time across the read window (was sample index, which compressed a two-minute silence into one step and joined its edges). A new subpath starts after any undrawable reading or silence; a reading alone between two breaks is drawn as a dot. Width, height, `currentColor` stroke, 1.5 width, 0.75 opacity, round caps and the supplied-batch rules are unchanged.
- **Full blue AreaChart** (`SignalTrendChart.tsx`, `TrendPlot`): same Mantine AreaChart, `blue.6`, linear curve, 320 px, `connectNulls={false}`, dot rule (<= 60 drawn) and Parameter/Range/custom controls. The axis is now a numeric time axis over the selected window (was a category axis of formatted labels); rows carry timestamped nulls and silence breaks, so nothing is joined across missing time; isolated readings get a dot on dense charts. Ticks fall on whole minutes and are sized to the plot (Performance pattern), so a phone shows a 5-minute grid.
- **Truthful states (screen 14):** recorded zero is a drawn line; a successful read with no readings is **No samples** (row) / "No samples in this window ... different from a recorded zero" (chart) — before, the row said "Too few samples"; a failed batch read is **Read failed** (before: "No trend", indistinguishable from a source without history); no connector / history unsupported / source unavailable keep their native reasons. One "Gaps in this record" disclosure states silences, non-numeric and not-good readings and undated readings; when the server states no cadence it says silences are not marked.
- **Source/time context:** the chart caption names the selected window with seconds and the reader's time zone, and says when times were moved onto the dashboard clock (`display_shifted`). Raw unitless channels keep no unit (screen 13).
- **Backend (only missing fact):** trend reads (`trend/` and `trends/`) now state `cadence_seconds` (median interval of the binding's own readings, sorted; null below three) and `limits.expected_sample_interval_seconds`, mirroring the series read's existing fields. No sample is filled, resampled or reordered on the server.
- **Shared fix found while capturing:** `WorkOrderCreateModal` passed an inline `validate` object to Mantine form, so `setFieldValue` changed identity every render and the packet-toggle effect looped ("Maximum update depth exceeded", hundreds per page load) wherever the modal is mounted — the machine header and the Health tab included — starving the tab. The rules are now a module constant; behaviour is unchanged.

## Captures inspected and what was fixed

Before (unchanged Health UI): `p09/before/*/health-{page,table,chart}-{light,dark}.png` and inventories. They show the defects: the chart's category axis compresses the 08:53-08:55 silence and joins it; the row graph uses index spacing; the empty read says "Too few samples".

After: `p09/after/s3-captures/` — `chart-silence-{light,dark}.png` (desktop and phone), `table-states.png`, native inventory captures. The inventory (row graphs 120 x 28 / currentColor / 1.5 / 0.75; AreaChart stroke `blue-6`, gradient fill, 320 px; Parameter and Range controls) is unchanged before and after on desktop and phone, light and dark.

Fixed from the captures:
1. Phone: the native Parameter select (`minWidth: 320`) overflowed the card at 390 px — now full width below `xs`, 320 px from `xs` up (desktop unchanged). Spec asserts containment.
2. Phone: with time-axis ticks only the two end labels survived — ticks are now sized to the plot and lose the always-":00" seconds (tooltips/caption keep full instants).
3. The final tick label is nudged inward by Recharts; the spec derives the time mapping from interior ticks.

Seen, left for P37 (its scope): State badges truncate to "NOR…"/icon-only in the narrow column, and on phones the Trend column is off-screen inside the native table scroll.

## Open items / missing facts

- **Report-by-exception sources:** the break threshold uses the measured (else expected) cadence. A source that writes only on change would need a per-source cadence/deadband fact, which no source model records. Not Blocked for the pump historian (5 s polled snapshots).
- Not-good-quality samples are drawn as breaks (same rule as Performance); that is a documented display decision, not a change to stored evidence.
- No R6 acceptance, live historian, deployment or human visual approval is claimed.
